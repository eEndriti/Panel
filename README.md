# 🧱 Cemento Management Desktop App

A desktop application built for a cement company to manage **clients, recipes-based stock, and delivery papers**.

> ⚠️ This repository contains a **simplified version**.  
> Business-specific and sensitive details are removed.

---

## 📊 Features

### 🏠 Dashboard
- Today & monthly **sales** (with comparisons)
- Today & monthly **KG** (with comparisons)
- Recent delivery papers
- ➕ Quick action to create delivery papers

### 📄 Delivery Papers (PDF)
- Select **client**
- Select **recipe** (not standard products)
- View products inside the recipe
- Enter quantity in **m³**
- Generate PDF delivery paper

### 👥 Clients
- Manage client records

### 🧪 Stock (Recipes-based)
- Stock is **recipe-based**, not product-based
- Each recipe contains multiple products

### ⚙️ Other
- All delivery papers history
- Application settings
